📌 About Project

AI Verify is a deepfake detection system that analyzes images, videos, and audio to identify manipulated content using machine learning models. It helps users verify authenticity and prevent misinformation.

⚙️ How to Use

1. Upload your media file (image, video, or audio)
2. Click "Scan now"
3. Wait for analysis results
4. View authenticity report with confidence score
